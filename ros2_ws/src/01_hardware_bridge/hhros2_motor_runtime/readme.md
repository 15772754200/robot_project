# readme

`_RT`这个函数是什么，这个不是C/C++标准语法里的函数，它大概率是你这个实时系统里定义的一个宏，用来把普通的`POSIX/socket`调用切换成实时版本调用

`AF_RTIPC`这个很像是实时系统里面的专用socket地址族

- `AF`这个是地址族的意思
- `RT`这个是实时的意思
- `IPC`这个是进程间通信的意思
- 总结起来就是实时的进程间通信的意思

`IPCPROTO_EXIPC`这个代表实时进程与非实时进程之间通信

这个ipc频率只有970Hz，说明它不是硬实时吧

应该我初步感觉，如果不是硬实时的话，就是这个做的操作太长了，不知道为什么，按照道理来说，它不会差别太大了
