# 模型格式说明

当前部署框架只支持 ONNX 模型推理，不再在部署端加载或转换其他模型格式。

要求：
1. 训练端提前导出 `.onnx` 模型。
2. 将 `.onnx` 文件放入对应策略目录，例如：
   `src/robot_pkg/src/policy/N1/N1_rl_gym/motion.onnx`
3. 在对应 `config.yaml` 中配置：
   `model_name: "motion.onnx"`
4. 保持 `num_observations`、`observation_stack`、`num_of_dofs` 与导出的 ONNX 输入/输出维度一致。

验证建议：
1. 执行 `colcon build --packages-select robot_pkg`。
2. 启动前确认策略目录存在配置中声明的 `.onnx` 文件。
3. 如果模型加载失败，优先检查文件路径、输入维度、ONNX Runtime 运行库是否随 `robot_pkg` 安装。
