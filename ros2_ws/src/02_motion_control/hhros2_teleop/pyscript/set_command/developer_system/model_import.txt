训练好的模型应该放在哪里？需要修改哪些配置文件？
1. 进入 ROS2 包路径
路径：ros2_pkg/robot_ros2/src/robot_pkg/src/policy
2. 里面有很多哥模型，包括了行走，跑步，模仿等，你将自己的模型放在相应的文件夹中，例如，你放在了N1_rl_run，这是一个行走的模型。
3. 修改congfig.yaml如下
（1）model_name是模型的名称
（2）num_observations是模型的输入观测维度
（3）observations是模型输入的组成部分
（4）observation_stack是观测堆叠的次数，堆叠的逻辑可在rl_sdk的ComputeObservation中看到，总体上是滑动窗口形式的
（5）clip_obs是obs的限制，clip_actions_lower，clip_actions_upper分别是动作限制的上限
（6）rl_kp，rl_kd是发给底层电机的pd参数，但是目前是位控，底层集成了pd参数。后续可以拓展。
（7）num_of_dofs是模型的输出的维数
（8）scale表示各个参数的缩放
（9）torque_limits是各个关节的力矩限制
（10）default_dof_pos是默认关节角
（11）joint_mapping是关节映射

4. 总之，需要你将仿真环境中的信息迁移到这里，如果没有，则需要添加。
