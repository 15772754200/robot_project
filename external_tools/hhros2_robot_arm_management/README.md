# 机器人机械臂管理工具

本目录保存与主 `hhros2` 工作空间解耦的机械臂示教、外设管理和系统管理工具。工具代码不修改主机器人框架的控制器、启动文件或 EtherCAT 后端。

| 目录 | 用途 | 是否直接控制实机 |
| --- | --- | --- |
| `arm_control_test/ros2_ws` | 八个手臂关节的实机录制与回放，以及保留的旧挥手仿真 | 实机示教可以；旧仿真不可以 |
| `peripheral_management` | USB、串口、网络、蓝牙、显示与音频设备扫描、查看和管理 | 否 |
| `system` | Linux 进程、存储、缓存和备份管理 | 否 |

## 使用边界

### 实机手臂示教

实机适配器使用当前框架的 `/joint_states`、`/humanoid_base_controller/reference` 和模式仲裁接口，管理左右手臂共八个关节。录制仅允许在站立模式执行；回放会申请 `MODE_MOTION=6`，结束或异常后请求返回站立模式。

详细的构建、录制、回放和安全检查说明见：

```text
arm_control_test/ros2_ws/README.md
```

### 旧 `wave_*` 仿真

`wave_*`、`motor_driver_sim`、`teach_manager` 和旧的五/六关节轨迹文件属于独立的遗留仿真演示。它们运行在 `/legacy_wave_sim` 命名空间，不使用当前实机命令话题、控制模式仲裁或 EtherCAT，因此不能用于驱动实机。

### 系统与外设工具

`peripheral_management` 和 `system` 是独立的 Linux 运维工具。它们不带机器人安全互锁，不应在机器人执行关键动作时随意禁用网络、蓝牙或终止 ROS 进程。

## 推荐使用顺序

1. 先启动并确认主机器人框架、反馈和站立控制正常。
2. 按机械臂工作空间说明构建并启动 `teach_real.launch.py`。
3. 在 `MODE_STAND=2` 下录制手臂动作。
4. 确认命令话题没有其他控制发布者后，再执行实机回放。
5. 仅在需要验证旧示例时单独启动 `wave_*` 仿真，不要将旧轨迹用于实机回放。
